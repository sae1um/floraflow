# Database

## Tables

Seventeen app tables plus Better Auth's four. Greenhouse and device are separate, so a broken board can be swapped without losing history.

| Table | Holds | Key |
| --- | --- | --- |
| `user`, `session`, `account`, `verification` | Accounts and sessions, generated by the Better Auth CLI | `user.id` (text) |
| `greenhouses` | Name, location, room, time zone, demo flag | `id` uuid |
| `greenhouse_members` | Who can see or control a greenhouse, and their role | (`greenhouse_id`, `user_id`) |
| `invites` | Shareable invite links with a role and expiry | `id`; `token_hash` unique |
| `devices` | Hardware: secret hash, firmware, online, last seen, current greenhouse | `id` = `GH-…` |
| `pairing_codes` | Short-lived codes shown on the LCD | `code_hash` |
| `readings` | Raw readings, kept 90 days | (`greenhouse_id`, `recorded_at`) |
| `readings_hourly` | Min/avg/max per hour, kept forever | (`greenhouse_id`, `bucket`) |
| `latest_readings` | One row per greenhouse: the newest reading | `greenhouse_id` |
| `greenhouse_settings` | Thresholds (JSON, validated by zod), config version, report interval | `greenhouse_id` |
| `schedules` | Actuator on/off windows by day | `id` |
| `commands` | Every command sent to a device and its status | `id` uuid |
| `actuator_events` | Every vent/light/pump change and what caused it | `id` identity |
| `alerts` | Threshold and offline alerts, open or resolved | `id` uuid |
| `push_subscriptions` | Each browser's web push endpoint and keys | `id`; `endpoint` unique |
| `notification_prefs` | Per-user push settings and when alerts were last seen | `user_id` |
| `firmware_releases` | Uploaded builds: version, MD5, size, storage path | `id`; `version` unique |
| sim\_devices | Virtual devices: owner, encrypted MQTT secret, environment, faults, physics snapshot, when to stop | device\_id |

## Entity relationship diagrams

Three diagrams, one per area, all meeting at `greenhouses`. Arrows point from the foreign key to the row it references; `tstz` means `timestamptz`.

&#91;embedded content: ERD 1 · accounts, sharing, notifications\]

Better Auth's `session`, `account` and `verification` tables also reference `user` but aren't shown. The `invited_by`, `accepted_by` and `created_by` links to `user` are left off to keep the picture readable.

&#91;embedded content: ERD 2 · devices, simulator, control\]

`firmware_releases` has no foreign keys: `devices.firmware_version` matches its `version` by value. `issued_by` and `updated_by` point at `user`.

&#91;embedded content: ERD 3 · telemetry and alerts\]

Readings key on greenhouse, not device, so a swapped board continues the same history.

## Drizzle schema

`packages/db/src/schema.ts`. Readings use `real` (4 bytes) and a composite primary key instead of a UUID, which roughly halves each row and its index. All timestamps are `timestamptz`.

```ts
import { sql } from "drizzle-orm";
import {
  pgTable, pgEnum, text, uuid, timestamp, real, integer, smallint,
  boolean, jsonb, bigint, time, primaryKey, index, uniqueIndex,
} from "drizzle-orm/pg-core";
import type { Thresholds, SimEnvironment, SimFaults, SimSnapshot } from "@floraflow/shared";
import { user } from "./auth-schema"; // generated by the Better Auth CLI

const ts = (name: string) => timestamp(name, { withTimezone: true });

export const memberRole = pgEnum("member_role", ["owner", "editor", "viewer"]);
export const deviceStatus = pgEnum("device_status", ["unclaimed", "active", "retired"]);
export const deviceKind = pgEnum("device_kind", ["physical", "simulated"]);
export const actuator = pgEnum("actuator", ["vent", "light", "pump"]);
export const commandType = pgEnum("command_type", ["setActuator", "clearOverride", "ota", "reboot", "identify"]);
export const commandStatus = pgEnum("command_status", ["pending", "sent", "acked", "failed", "expired"]);
export const eventSource = pgEnum("event_source", ["auto", "schedule", "manual", "boot"]);
export const alertType = pgEnum("alert_type", ["temp_high", "temp_low", "humidity_high", "soil_dry", "water_low", "co2_low", "device_offline"]);
export const severity = pgEnum("severity", ["info", "warning", "critical"]);

export const greenhouses = pgTable("greenhouses", {
  id: uuid("id").primaryKey().defaultRandom(),
  name: text("name").notNull(),
  location: text("location"),
  room: text("room"),
  timezone: text("timezone").notNull().default("Europe/London"),
  isDemo: boolean("is_demo").notNull().default(false),
  createdBy: text("created_by").notNull().references(() => user.id),
  createdAt: ts("created_at").notNull().defaultNow(),
  updatedAt: ts("updated_at").notNull().defaultNow(),
});

export const greenhouseMembers = pgTable("greenhouse_members", {
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  role: memberRole("role").notNull(),
  createdAt: ts("created_at").notNull().defaultNow(),
}, (t) => [
  primaryKey({ columns: [t.greenhouseId, t.userId] }),
  index("members_user_idx").on(t.userId),
]);

export const invites = pgTable("invites", {
  id: uuid("id").primaryKey().defaultRandom(),
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  role: memberRole("role").notNull(),
  tokenHash: text("token_hash").notNull().unique(),
  invitedBy: text("invited_by").notNull().references(() => user.id),
  expiresAt: ts("expires_at").notNull(),
  acceptedBy: text("accepted_by").references(() => user.id),
  acceptedAt: ts("accepted_at"),
});

export const devices = pgTable("devices", {
  id: text("id").primaryKey(), // GH-XXXXXXXXXXXX
  secretHash: text("secret_hash").notNull(), // SHA-256 hex
  greenhouseId: uuid("greenhouse_id").references(() => greenhouses.id, { onDelete: "set null" }),
  status: deviceStatus("status").notNull().default("unclaimed"),
  kind: deviceKind("kind").notNull().default("physical"),
  firmwareVersion: text("firmware_version"),
  hardwareRev: text("hardware_rev"),
  online: boolean("online").notNull().default(false),
  lastSeenAt: ts("last_seen_at"),
  rssi: smallint("rssi"),
  configVersionAcked: integer("config_version_acked").notNull().default(0),
  claimedAt: ts("claimed_at"),
  createdAt: ts("created_at").notNull().defaultNow(),
}, (t) => [
  uniqueIndex("devices_greenhouse_uq").on(t.greenhouseId).where(sql`${t.greenhouseId} is not null`),
]);

export const pairingCodes = pgTable("pairing_codes", {
  codeHash: text("code_hash").primaryKey(),
  deviceId: text("device_id").notNull().references(() => devices.id, { onDelete: "cascade" }),
  expiresAt: ts("expires_at").notNull(),
  usedAt: ts("used_at"),
}, (t) => [index("pairing_device_idx").on(t.deviceId)]);

export const readings = pgTable("readings", {
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  recordedAt: ts("recorded_at").notNull(),
  deviceId: text("device_id").notNull(), // no FK: history outlives a removed device
  tempC: real("temp_c"),
  humidityPct: real("humidity_pct"),
  soilPct: real("soil_pct"),
  lux: real("lux"),
  waterPct: real("water_pct"),
  co2Ppm: smallint("co2_ppm"),
}, (t) => [primaryKey({ columns: [t.greenhouseId, t.recordedAt] })]);

export const readingsHourly = pgTable("readings_hourly", {
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  bucket: ts("bucket").notNull(), // start of the hour, UTC
  samples: smallint("samples").notNull(),
  tempCMin: real("temp_c_min"), tempCAvg: real("temp_c_avg"), tempCMax: real("temp_c_max"),
  humidityPctMin: real("humidity_pct_min"), humidityPctAvg: real("humidity_pct_avg"), humidityPctMax: real("humidity_pct_max"),
  soilPctMin: real("soil_pct_min"), soilPctAvg: real("soil_pct_avg"), soilPctMax: real("soil_pct_max"),
  luxMin: real("lux_min"), luxAvg: real("lux_avg"), luxMax: real("lux_max"),
  waterPctMin: real("water_pct_min"), waterPctAvg: real("water_pct_avg"), waterPctMax: real("water_pct_max"),
  co2PpmAvg: real("co2_ppm_avg"), co2PpmMax: real("co2_ppm_max"),
}, (t) => [primaryKey({ columns: [t.greenhouseId, t.bucket] })]);

export const latestReadings = pgTable("latest_readings", {
  greenhouseId: uuid("greenhouse_id").primaryKey().references(() => greenhouses.id, { onDelete: "cascade" }),
  recordedAt: ts("recorded_at").notNull(),
  tempC: real("temp_c"),
  humidityPct: real("humidity_pct"),
  soilPct: real("soil_pct"),
  lux: real("lux"),
  waterPct: real("water_pct"),
  co2Ppm: smallint("co2_ppm"),
});

export const greenhouseSettings = pgTable("greenhouse_settings", {
  greenhouseId: uuid("greenhouse_id").primaryKey().references(() => greenhouses.id, { onDelete: "cascade" }),
  version: integer("version").notNull().default(1),
  thresholds: jsonb("thresholds").$type<Thresholds>().notNull(),
  telemetryIntervalS: smallint("telemetry_interval_s").notNull().default(60),
  updatedBy: text("updated_by").references(() => user.id),
  updatedAt: ts("updated_at").notNull().defaultNow(),
});

export const schedules = pgTable("schedules", {
  id: uuid("id").primaryKey().defaultRandom(),
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  actuator: actuator("actuator").notNull(),
  startTime: time("start_time").notNull(),
  endTime: time("end_time").notNull(),
  daysMask: smallint("days_mask").notNull(), // bit 0 = Sunday ... bit 6 = Saturday
  enabled: boolean("enabled").notNull().default(true),
  createdAt: ts("created_at").notNull().defaultNow(),
}, (t) => [index("schedules_gh_idx").on(t.greenhouseId)]);

export const commands = pgTable("commands", {
  id: uuid("id").primaryKey().defaultRandom(),
  deviceId: text("device_id").notNull().references(() => devices.id, { onDelete: "cascade" }),
  greenhouseId: uuid("greenhouse_id").references(() => greenhouses.id, { onDelete: "cascade" }),
  type: commandType("type").notNull(),
  payload: jsonb("payload").notNull(),
  status: commandStatus("status").notNull().default("pending"),
  issuedBy: text("issued_by").references(() => user.id),
  error: text("error"),
  createdAt: ts("created_at").notNull().defaultNow(),
  sentAt: ts("sent_at"),
  ackedAt: ts("acked_at"),
}, (t) => [
  index("commands_device_created_idx").on(t.deviceId, t.createdAt.desc()),
  index("commands_open_idx").on(t.status).where(sql`${t.status} in ('pending', 'sent')`),
]);

export const actuatorEvents = pgTable("actuator_events", {
  id: bigint("id", { mode: "number" }).primaryKey().generatedAlwaysAsIdentity(),
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  actuator: actuator("actuator").notNull(),
  value: smallint("value").notNull(), // 0/1 for light and pump, 0-100 for vent %
  source: eventSource("source").notNull(),
  commandId: uuid("command_id"),
  recordedAt: ts("recorded_at").notNull(),
}, (t) => [index("events_gh_time_idx").on(t.greenhouseId, t.recordedAt.desc())]);

export const alerts = pgTable("alerts", {
  id: uuid("id").primaryKey().defaultRandom(),
  greenhouseId: uuid("greenhouse_id").notNull().references(() => greenhouses.id, { onDelete: "cascade" }),
  type: alertType("type").notNull(),
  severity: severity("severity").notNull(),
  value: real("value"),
  threshold: real("threshold"),
  message: text("message").notNull(),
  startedAt: ts("started_at").notNull().defaultNow(),
  resolvedAt: ts("resolved_at"),
  acknowledgedBy: text("acknowledged_by").references(() => user.id),
  acknowledgedAt: ts("acknowledged_at"),
}, (t) => [
  index("alerts_gh_started_idx").on(t.greenhouseId, t.startedAt.desc()),
  uniqueIndex("alerts_one_open_uq").on(t.greenhouseId, t.type).where(sql`${t.resolvedAt} is null`),
]);

export const pushSubscriptions = pgTable("push_subscriptions", {
  id: uuid("id").primaryKey().defaultRandom(),
  userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  endpoint: text("endpoint").notNull().unique(),
  p256dh: text("p256dh").notNull(),
  auth: text("auth").notNull(),
  userAgent: text("user_agent"),
  createdAt: ts("created_at").notNull().defaultNow(),
  lastSuccessAt: ts("last_success_at"),
}, (t) => [index("push_user_idx").on(t.userId)]);

export const notificationPrefs = pgTable("notification_prefs", {
  userId: text("user_id").primaryKey().references(() => user.id, { onDelete: "cascade" }),
  pushEnabled: boolean("push_enabled").notNull().default(true),
  minSeverity: severity("min_severity").notNull().default("warning"),
  alertsSeenAt: ts("alerts_seen_at"),
});

export const simDevices = pgTable("sim_devices", {
  deviceId: text("device_id").primaryKey().references(() => devices.id, { onDelete: "cascade" }),
  ownerId: text("owner_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  secretEnc: text("secret_enc").notNull(), // AES-GCM with SIM_SECRET_KEY
  environment: jsonb("environment").$type<SimEnvironment>().notNull(),
  faults: jsonb("faults").$type<SimFaults>().notNull(),
  snapshot: jsonb("snapshot").$type<SimSnapshot>(), // saved every minute
  running: boolean("running").notNull().default(true),
  stopAt: ts("stop_at"), // null = always on (shared demo devices)
  createdAt: ts("created_at").notNull().defaultNow(),
}, (t) => [index("sim_owner_idx").on(t.ownerId)]);

export const firmwareReleases = pgTable("firmware_releases", {
  id: uuid("id").primaryKey().defaultRandom(),
  version: text("version").notNull().unique(),
  storagePath: text("storage_path").notNull(),
  md5: text("md5").notNull(),
  sizeBytes: integer("size_bytes").notNull(),
  notes: text("notes"),
  createdBy: text("created_by").references(() => user.id),
  createdAt: ts("created_at").notNull().defaultNow(),
});
```

## Indexes

Every index exists for a named query; there are no speculative ones.

| Index | Serves |
| --- | --- |
| `readings` PK (`greenhouse_id`, `recorded_at`) | Chart range queries; also ignores resent buffered readings |
| `readings_hourly` PK (`greenhouse_id`, `bucket`) | Charts longer than 48 h; idempotent rollup upserts |
| `latest_readings` PK (`greenhouse_id`) | Overview cards in one query |
| `members_user_idx` (`user_id`) | "My greenhouses" |
| `devices_greenhouse_uq` partial unique | One device per greenhouse |
| `alerts_one_open_uq` partial unique (`greenhouse_id`, `type`) where open | No duplicate open alerts; upsert target for alert evaluation |
| `alerts_gh_started_idx` | Alert history per greenhouse |
| `commands_device_created_idx` | Command history on the device page |
| `commands_open_idx` partial (`status` pending/sent) | 15-second timeout sweep |
| `events_gh_time_idx` | Actuator timeline under the chart |
| `push_user_idx` | Fan-out of a web push to a user's browsers |

**At hundreds of devices:** partition `readings` by month and drop whole partitions instead of deleting rows.

## Rollups, retention and sizing

Supabase Cron (`pg_cron`) runs three jobs inside the database, so the API stays stateless. They live in a hand-written migration, `0002_cron.sql`.

```sql
-- Every hour at :05: (re)build the last 3 hours, so late buffered readings are counted
select cron.schedule('rollup-hourly', '5 * * * *', $$
  insert into readings_hourly as h (
    greenhouse_id, bucket, samples,
    temp_c_min, temp_c_avg, temp_c_max,
    humidity_pct_min, humidity_pct_avg, humidity_pct_max,
    soil_pct_min, soil_pct_avg, soil_pct_max,
    lux_min, lux_avg, lux_max,
    water_pct_min, water_pct_avg, water_pct_max,
    co2_ppm_avg, co2_ppm_max)
  select greenhouse_id, date_trunc('hour', recorded_at), count(*),
    min(temp_c), avg(temp_c), max(temp_c),
    min(humidity_pct), avg(humidity_pct), max(humidity_pct),
    min(soil_pct), avg(soil_pct), max(soil_pct),
    min(lux), avg(lux), max(lux),
    min(water_pct), avg(water_pct), max(water_pct),
    avg(co2_ppm), max(co2_ppm)
  from readings
  where recorded_at >= date_trunc('hour', now()) - interval '3 hours'
    and recorded_at <  date_trunc('hour', now())
  group by 1, 2
  on conflict (greenhouse_id, bucket) do update set
    samples = excluded.samples,
    temp_c_min = excluded.temp_c_min, temp_c_avg = excluded.temp_c_avg, temp_c_max = excluded.temp_c_max,
    humidity_pct_min = excluded.humidity_pct_min, humidity_pct_avg = excluded.humidity_pct_avg, humidity_pct_max = excluded.humidity_pct_max,
    soil_pct_min = excluded.soil_pct_min, soil_pct_avg = excluded.soil_pct_avg, soil_pct_max = excluded.soil_pct_max,
    lux_min = excluded.lux_min, lux_avg = excluded.lux_avg, lux_max = excluded.lux_max,
    water_pct_min = excluded.water_pct_min, water_pct_avg = excluded.water_pct_avg, water_pct_max = excluded.water_pct_max,
    co2_ppm_avg = excluded.co2_ppm_avg, co2_ppm_max = excluded.co2_ppm_max;
$$);

-- Daily 03:15 UTC: raw readings older than 90 days
select cron.schedule('retention-raw', '15 3 * * *', $$
  delete from readings where recorded_at < now() - interval '90 days';
$$);

-- Daily 03:30 UTC: housekeeping
select cron.schedule('housekeeping', '30 3 * * *', $$
  delete from pairing_codes where expires_at < now() - interval '1 day';
  delete from commands where created_at < now() - interval '30 days';
  delete from invites where expires_at < now() - interval '7 days' and accepted_at is null;
$$);
```

**Chart query.** Ranges up to 48 h read `readings`; longer ranges read `readings_hourly`. Either way the API buckets to about 300 points, so a chart never gets more:

```sql
-- $bucket = greatest(range / 300, 60 seconds)
select date_bin($bucket, recorded_at, $from) as t,
       avg(temp_c) as temp_c, avg(humidity_pct) as humidity_pct, avg(soil_pct) as soil_pct,
       avg(lux) as lux, avg(water_pct) as water_pct, avg(co2_ppm) as co2_ppm
from readings
where greenhouse_id = $id and recorded_at >= $from and recorded_at < $to
group by 1 order by 1;
```

**Storage estimate.** A raw row plus its index entry is roughly 100 bytes.

| Devices | Raw, 90 days | Hourly, per year | Fits 500 MB? |
| --- | --- | --- | --- |
| 1 | \~13 MB | \~2 MB | Yes |
| 20 | \~260 MB | \~35 MB | Yes |
| 100 | \~1.3 GB | \~175 MB | No: Pro plan or a 30-day raw window |

**Migrations:** `drizzle-kit generate` from the schema; CI runs `drizzle-kit migrate` against Supabase on merge to main, before Render deploys.
